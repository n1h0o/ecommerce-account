# Реестр материалов

- `public/products/ceramics-sheet.png` — созданное для проекта изображение предметной фотосессии четырёх вымышленных керамических изделий (генерация Codex ImageGen, 26.10.2026). В интерфейсе каждая четверть используется отдельным изделием; надписи и логотипы отсутствуют.
- Шрифт Inter Tight подключается через Google Fonts, с fallback Inter и системным гротеском.
- Референс: Palmer из каталога Refero Styles, только для изучения визуального направления. Его графика и код не используются.
- Тексты, каталог, цены, остатки, компания, аккаунт и заказы придуманы для демо.
