# Прибой — магазин авторской керамики

Демо-магазин небольшой мастерской: предметный каталог, оригинальная фотосъёмка, категории, сортировка, избранное, быстрый просмотр, корзина с количеством, код `PRIBOI10`, локальный checkout и профиль с историей заказов.

Всё выполняется только во вкладке. Приложение не подключает backend, не списывает оплату и не отправляет данные. Товары, аккаунт и заказ — вымышленные демонстрационные записи.

## Запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```
